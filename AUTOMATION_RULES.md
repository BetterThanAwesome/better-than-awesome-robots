# Automation Rules

Automation may read all public content in this repository.

Automation may create draft robot records and draft articles.

Automation should use branches and pull requests for content changes.

Automation must not publish content by changing `status` to `published` unless an approved workflow explicitly allows it.

Automation must never commit secrets, customer leads, email addresses, private quotes, credentials or confidential procurement material.

Price, specification and availability changes should include a source and a verification date.

Regional content should be localized rather than mechanically translated when practical.
